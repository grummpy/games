# Cat Girl Fighters

Current version: **1.4.0**

An adult arcade fighting game built with HTML5 Canvas and photo sprites.

## Start the game

Keep the files and `game_sprites` folder together, then open `cat_girl_fighters.html` in a modern browser.

## Controls

### 1P vs AI

- Move: W/A/S/D or arrow keys
- Punch: J
- Kick: K
- Block: L
- Power: Space
- Pause: P

### 2P local

- Player 1: W/A/S/D, J/K/L, Space
- Player 2: arrow keys, 1/2/3, 0 or Enter
- Pause: P

## Music

`neon-combat.m4a` is included as the optimized looping battle soundtrack. Use the `MUSIC: ON/OFF` button in the lower-right corner. Music pauses with the game and resumes when the fight continues.
